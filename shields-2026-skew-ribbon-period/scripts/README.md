# Computational supplement — Minimal-period rigidity for ribbon-outer skew Schur compositions

Cross-check scripts for `shields-2026-skew-ribbon-period.tex` build skew diagrams, marked inners and compositions from cell sets, and derive finite Jacobi–Trudi matrices from their beta lists.  They compare exact polynomial differentiation with full row and column replacements, check the composition normalizers and corner formulas with exact Schur functions, solve the contact vectors of the contact-rigidity theorem from their defining equations, and construct actual empty-chart witnesses from translated cell sets.

The paper proves ribbon-outer period selection under the stated strictly smaller-area classification hypothesis.  These checks exercise determinant identities and boundary conventions; they do not discharge that hypothesis or prove general geometric recognition.

The proofs in the paper are noncomputational and do not depend on the code here.

## Installation

Use Python 3.10 or later.  Install the pinned dependencies and run the harness:

```sh
python3 -m pip install -r requirements.txt
bash run_all.sh
```
