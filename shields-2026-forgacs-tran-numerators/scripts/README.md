# Computational supplement

Verification scripts for *Bounded exceptional zeros for polynomial initial data
in the Forgács–Tran family*.  Every script re-derives what it checks from the
generating function

    N(t, z) / (Q(t) + z t^r) = Σ_{m≥0} P_m(z) t^m,

through the exact coefficient recurrence, so the identities are pinned to the
objects that define them rather than transcribed.  Symbolic work uses SymPy;
numerical work uses mpmath at arbitrary precision (no floating-point arithmetic
in the verification loops), with denominator roots taken from `mpmath.polyroots`.

Reference environment: Python 3.12, SymPy 1.14.0, mpmath 1.3.0.

```bash
python -m pip install -r requirements.txt
./run_all.sh
```
